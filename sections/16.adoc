== 第十六章

[#L16-1]
致虛極，守靜篤。萬物並作，吾以觀復。

[#L16-2]
夫物芸芸，各復歸其根。歸根曰靜，是謂復命。

[#L16-3]
復命曰常，知常曰明。不知常，妄作凶。

[#L16-4]
知常容，容乃公，公乃王，王乃天，天乃道，道乃久，沒身不殆。
