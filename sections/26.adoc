== 第二十六章

[#L26-1]
重為輕根，靜為躁君。是以聖人終日行不離輜重。

[#L26-2]
雖有榮觀，燕處超然。奈何萬乘之主，而以身輕天下？

[#L26-3]
輕則失本，躁則失君。
