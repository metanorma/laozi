== 第二十二章

[#L22-1]
曲則全，枉則直，窪則盈，敝則新，少則得，多則惑。

[#L22-2]
是以聖人抱一為天下式。

[#L22-3]
不自見故明，不自是故彰，不自伐故有功，不自矜故長。

[#L22-4]
夫唯不爭，故天下莫能與之爭。

[#L22-5]
古之所謂曲則全者，豈虛言哉！誠全而歸之。
